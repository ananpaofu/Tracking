# 收纳小管家 · 手机版

一个纯前端的物品收纳记录 App，让每件物品都有迹可循。数据保存在浏览器本地，无需联网即可使用。

## 功能特性

- **新手教程**：首次进入自动弹出 5 步操作引导
- **物品管理**：拍照识物（本地 AI 模拟）、分类、数量、保质期、存放位置
- **智能排序**：到期优先 / A-Z 字母 / 最近收纳
- **收纳地图**：按位置（冰箱、柜子等）归类，支持自定义位置自动同步
- **搜索**：搜索历史、展开、一键清空
- **到期提醒**：临期与过期物品自动排前
- **设备联动**：蓝牙模拟搜索连接、定位标签查找、离位提醒
- **好友与群聊**：编号 ID 加好友、文字、表情、表情包导入、聊天背景更换
- **个性化设置**：微信风格设置页，可改头像昵称、字号粗细、主题色

## 本地运行

直接用浏览器打开 `index.html` 即可。

若要完整测试拍照、定位等需要安全上下文的功能，可用本地服务器方式打开：

```bash
# Python
python -m http.server 8000

# 或 Node.js
npx serve .
```

然后访问 `http://localhost:8000`。

## 部署到 GitHub Pages

1. 将本目录下的所有文件上传到 GitHub 仓库
2. 进入仓库 **Settings → Pages**
3. Source 选择 **Deploy from a branch**，分支选 `main`，目录选 `/ (root)`
4. 保存后等待部署完成，访问 `https://<用户名>.github.io/<仓库名>/`

## 安装到手机桌面（PWA）

部署到 GitHub Pages（HTTPS）后：

- **安卓 Chrome**：打开网址 → 右上角菜单 → 「安装应用 / 添加到主屏幕」，确认后即可像普通 App 一样全屏打开。
- **苹果 Safari**：打开网址 → 底部分享按钮 → 「添加到主屏幕」。

> 必须把所有文件（含 `manifest.webmanifest` 和 `sw.js`）一起上传，且通过 HTTPS 访问（GitHub Pages 符合），浏览器才会显示安装选项。

## 文件说明

| 文件 | 说明 |
|------|------|
| `index.html` | 入口页面（手机外框 + 状态栏） |
| `manifest.webmanifest` | PWA 应用清单（安装到桌面用） |
| `sw.js` | Service Worker（离线缓存 / PWA 安装用） |
| `mobile.css` | 全部样式 |
| `mobile.js` | 全部逻辑（约 2000+ 行，纯原生 JS，无依赖） |

## 技术说明

- 纯原生 HTML / CSS / JavaScript，无任何第三方依赖
- 数据通过 `localStorage` 持久化（key: `organizer_db_v1`）
- AI 识物、蓝牙连接、跨用户好友均为本地模拟，无后端服务
- 支持响应式：桌面显示手机外框，手机端全屏显示
